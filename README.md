# PG Finder fictional inventory API — CallKaro FDE assignment

A working FastAPI service to find **PG Finder-operated fictional properties**. There are 15 records in 3 Indian cities in `properties.json`; all names and prices are invented specifically for the assignment. Search is deterministic, read-only, and returns at most three options. It does not confirm availability, take payments or book rooms.

## 1. Run locally

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Visit `http://127.0.0.1:8000/docs` to interactively test, or:

```bash
curl -X POST http://127.0.0.1:8000/search_pgs \
  -H 'Content-Type: application/json' \
  -d '{"city":"Bangalore","area":"Koramangala","pg_type":"boys","max_budget":12000,"room_type":"sharing"}'
```

Expected: `matches_found`, with **PG Finder Cedar Nest** (₹8,500) and **PG Finder Maple Residency** (₹11,000). Test `http://127.0.0.1:8000/health` too.

## 2. Deploy an HTTPS endpoint

Push the files in this directory to your GitHub repository, then create a Python web service on Render (or another compatible host).

- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
- Health route: `/health`
- `render.yaml` is supplied as an optional deployment blueprint.

Hosting plans and deployment UIs change; choose a plan suitable for your testing needs. After deployment, test `https://YOUR-HOST/health` and `https://YOUR-HOST/docs`. An external voice service cannot call a `localhost` URL. Some sleeping/cold-start hosting plans can add unwanted tool latency during a call.

## 3. Configure CallKaro's In-Call Function

In the **Functions** section of your voice agent, add an **In-Call** HTTP/API function, using the current UI options (field names may differ):

- Function name: `search_pgs`
- Function description: `Search PG Finder-owned fictional properties by city, area, PG type, maximum monthly budget and room preference. Invoke after collecting all five requirements, and again whenever preferences change.`
- Method: `POST`
- URL: `https://YOUR-HOST/search_pgs`
- Header: `Content-Type: application/json`
- JSON request body fields:
  - `city` (string)
  - `area` (string)
  - `pg_type` (string; `boys`, `girls`, `co-living`)
  - `max_budget` (integer INR)
  - `room_type` (string; `single`, `sharing`)

If the form requires a JSON Schema, use the following **argument schema**:

```json
{
  "type": "object",
  "properties": {
    "city": {"type":"string", "description":"Caller city"},
    "area": {"type":"string", "description":"Preferred locality"},
    "pg_type": {"type":"string", "enum":["boys","girls","co-living"]},
    "max_budget": {"type":"integer", "description":"Maximum monthly rent in INR"},
    "room_type": {"type":"string", "enum":["single","sharing"]}
  },
  "required": ["city","area","pg_type","max_budget","room_type"]
}
```

**Important:** The above describes the API contract. It is **not** a CallKaro agent export JSON. Verify the actual Function form in the dashboard before entering it; some CallKaro modes may require mapping parameters to request body variables.

Paste `CALLKARO_PROMPT_ADDENDUM.txt` into the **Instructions** section you already wrote. Keep the existing Role, Goal, Call Flow and Guardrails.

## 4. Three voice call tests

1. **Hinglish success:** “Koramangala mein boys PG chahiye, 12k budget, sharing.” Should recommend Cedar Nest and Maple Residency at correct prices.
2. **Change of mind:** Same request, then “Actually single room chahiye, budget 18k.” Should call tool again and suggest the same two properties with single room prices ₹15,500 / ₹17,000.
3. **No match:** “Pune, Hinjewadi, girls PG, ₹8,000 sharing.” Must honestly say there is no exact match and request permission to adjust the constraint.

Also test city-only, unclear area, interrupted responses, existing-resident complaint, wrong number and callback close. For the actual submission, export the **agent JSON from CallKaro** and obtain **two real test-call recording links**. Neither is generated by this backend.

## 5. Run automated API tests

```bash
pip install pytest httpx
pytest -q
```

## Safety / scope

- Strict matching on city, area, PG type and room type; price must not exceed budget.
- Unknown area or type results in no recommendation rather than silently widening the search.
- The results list does not imply current occupancy or confirmed availability.
- No login or authentication is included because this is a read-only fictional demo. Add authentication if extending beyond the assignment.
